# java-course-journal

Изменяемые артефакты курса «Java Backend 17/21/25 на pet-проектах». Неизменяемые материалы (программа, карта порогов, методология, критерии, банк диагностик) лежат в Claude Project.

## Структура
- `journal.md` — журнал прогресса: статусы порогов, лог диалогов, очередь повторения. **Главная память курса**: ИИ читает его в начале каждого занятия.
- `cards.md` — карточки распределённого повторения, добавленные по ходу курса (базовый банк — в проекте).
- `reflections/` — рефлексии трансформации порогов (`T1.md` … `T10.md`) и эссе capstone.

ADR и постмортемы живут не здесь, а в репозиториях самих pet-проектов (`docs/adr/`, `docs/postmortems/`).

## Рабочий цикл
1. Перед занятием: журнал закоммичен и запушен (иначе ИИ прочитает старую версию).
2. Занятие: один чат в Claude Project («Урок», «Код-ревью», «Дебаг», «Экзамен порога», «Ретро», «Где я?»).
3. После занятия ИИ выдаёт блоки для коммита: новая запись лога, изменённые строки статусов, новые карточки, при зачёте порога — файл рефлексии. Внести, закоммитить: `dialog-NN: <тема>`.

Имена файлов латиницей — чтобы raw-ссылки оставались чистыми. История коммитов журнала — ваша хроника обучения: по ней видно и темп, и прохождение порогов.
